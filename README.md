# 🌐 Responsive Landing Page & Interactive Nav

A modern, single-page landing page featuring a highly interactive navigation bar. The project focuses on user experience (UX) by providing visual feedback through scroll-triggered styling and hover effects.

## ✨ Features

  * **Interactive Navigation:** The menu changes background color and style dynamically when the user scrolls down the page.
  * **Sticky Header:** The navigation bar remains fixed at the top for constant accessibility.
  * **Hover Effects:** Smooth transitions and color changes when hovering over menu items.
  * **Fully Responsive:** Adapts perfectly to mobile, tablet, and desktop screens using Media Queries.
  * **Clean UI:** A minimalist and professional design suitable for a variety of use cases.

## 🛠 Tech Stack

  * **HTML5:** Semantic markup for the header, sections, and navigation.
  * **CSS3:** Custom properties (variables), Flexbox, and transitions for smooth styling.
  * **JavaScript (Vanilla):** Event listeners for window scrolling and active state management.
